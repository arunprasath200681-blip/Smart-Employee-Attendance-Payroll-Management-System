Project Architecture & Technologies

Designed purely using HTML, CSS, JavaScript, Java, and MySQL with zero frameworks.

☕

Java (Backend Server)

Uses Java SE's built-in com.sun.net.httpserver.HttpServer. Handles REST endpoints, multithreaded requests, and static file serving without Spring Boot or Maven.

  • Main.java: Server startup and route mapping
  • DBConnection.java: Standard JDBC connection
  • EmployeeHandler.java: Employee CRUD operations
  • AttendanceHandler.java: Attendance tracking
  • PayrollHandler.java: Smart salary calculations
🐬

MySQL (Database)

Relational database management system storing persistent records with referential integrity and foreign keys.

  • Database: smart_payroll_db
  • employees: Stores employee profiles & base salary
  • attendance: Tracks daily check-in/out and statuses
  • payroll: Records calculated monthly payslips
🌐

HTML5 & Modern CSS3

Clean, semantic markup styled with responsive Flexbox and CSS Grid. Zero frontend frameworks (no Bootstrap, no React) - 100% beginner friendly.

  • Responsive layouts for desktop, tablet, and mobile
  • Interactive modal dialogs & toast alerts
  • Printable formatted payslip view
⚡

JavaScript (Vanilla JS)

Pure client-side JavaScript using modern ES6+ fetch() API to interact seamlessly with Java backend endpoints.

  • Single Page Application (SPA) tab switching
  • Live search filtering & dynamic DOM rendering
  • Instant UI feedback with toasts
